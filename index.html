SOP TERMUX GIT

Panduan Strategis Hosting Website ke GitHub Pages.

01

SETUP ENVIRONMENT

Wajib Sekali

Pastikan sistem Termux siap dan identitas developer terdaftar.

pkg update && pkg upgrade
pkg install git
git config --global user.name "namakamu"
git config --global user.email "emailkamu@gmail.com"
git config --global credential.helper store
02

INISIALISASI PROYEK

Internal Lebih Aman

Pilih folder di internal ~/ untuk menghindari masalah permission.

cd ~
mkdir nama-project && cd nama-project
git init -b main
⚠️ JIKA DI SD CARD: Jalankan git config --global --add safe.directory $(pwd)
03

KONTEN & COMMIT

Wajib index.html

Buat file dan simpan perubahan ke database Git lokal.

echo "<h1>Hello World</h1>" > index.html
git add .
git commit -m "Initial commit"
04

KONEKSI & PUSH

Gunakan PAT

Hubungkan ke repo GitHub dan kirim file. Gunakan Token sebagai password.

git remote add origin https://github.com/USERNAME/REPO.git
git push -u origin main

💡 RUMUS 3-P (RUTINITAS)

Setiap kali ada perubahan kode, jalankan:

1. git add .
2. git commit -m "Update"
3. git push
