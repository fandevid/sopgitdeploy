TERMUX GIT SOP

No more errors. Just push it.

FASE 1

Setup Awal Sistem

Lakukan ini satu kali saja saat install ulang Termux.

pkg update && pkg upgrade && pkg install git
git config --global user.name "user" && git config --global user.email "user@gmail.com"
git config --global credential.helper store
FASE 2

Buat Project Baru

Gunakan perintah ini untuk memulai folder project baru di internal.

cd ~ && mkdir project-name && cd project-name && git init -b main
PENTING: Buat repo di GitHub dulu, baru push di bawah ini.
git add . && git commit -m "Initial commit" && git push -u origin main
FASE 3

Update Konten (Harian)

Ritual 3-P setiap kali mengubah file.

git add . && git commit -m "Update konten" && git push
