GITHUB TERMUX
GUIDE FOR BEGINNER

Step 1: Init Proyek

Mulai dari Nol

Jalankan ini di dalam folder proyek baru Anda:

1. Aktifkan Git di folder ini:

git init -b main

2. Beri izin folder (WAJIB jika di SD CARD):

git config --global --add safe.directory $(pwd)

3. Buat file index sebagai penanda:

echo "<h1>Project Fandevid</h1>" > index.html
Step 2: Menghubungkan

Remote Ke Cloud

Pastikan sudah buat REPO di website GitHub dulu!
Ganti USER & REPO sesuai akunmu!

1. Hubungkan ke GitHub:

git remote add origin https://github.com/USER/REPO.git

2. Jika salah alamat, gunakan ini untuk ganti:

git remote set-url origin https://github.com/USER/REPO.git
Step 3: Upload

Kirim Data

1. Bungkus filenya:

git add . && git commit -m "Initial push"

2. Kirim ke Internet (Gunakan Token PAT):

git push -u origin main
Update Cepat

Besok-Besok Cukup Jalankan Ini:

git add . && git commit -m "Update" && git push
